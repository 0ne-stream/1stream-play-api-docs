# Documentation Structure

This directory contains detailed API documentation.

## Files

- `README.md` - Main documentation file
- `openapi.yaml` - OpenAPI/Swagger specification
- `examples/` - Code examples for different languages
- `guides/` - Integration guides

## Adding Documentation

When adding new endpoints:
1. Update `openapi.yaml` with the endpoint specification
2. Add detailed documentation to `README.md`
3. Add code examples to `examples/` directory if needed
